# 第 1 章 电路定律 | 本章一句话：先把 KCL 写对，你才有资格耍起。

{{必考}} {{5 题}} {{建议 40 分钟}}

## 一、选择题

### 1-1 {{基础}} {{3 分}}
电流从电压的“+”端流入，这一对参考方向称为：

A. 非关联参考方向  
B. 关联参考方向  
C. 真实方向  
D. 参考电位

::: answer 第 1-1 题 · 答案
**B**
:::

::: grandma 老奶解析
把电流想成水，电压想成水压。水从高压那头流进用电器，再从低压那头出来，这就是“顺着压力走”。

顺着压力走的方向，就叫**关联参考方向**。反过来，从“−”端流进去，就叫非关联。
所以记住一句话：**从“+”进，就是关联。**
:::

::: muscle 薄肌秒杀
- 考点：关联参考方向的判定。
- 步骤：看电流箭头是不是从电压“+”端进入 → 是则关联。
- 陷阱：参考方向是人为标的，和真实方向无关；负号只说明真实方向相反。
:::

### 1-2 {{进阶}} {{3 分}}
某元件电压和电流取关联参考方向，测得 U = −5 V，I = 2 A，则该元件：

A. 吸收 10 W  
B. 发出 10 W  
C. 吸收 2.5 W  
D. 发出 2.5 W

::: answer 第 1-2 题 · 答案
**B**（P = UI = −10 W，关联方向下 P<0 表示发出）
:::

::: grandma 老奶解析
先算功率：P = U × I = (−5) × 2 = −10 W。

负号不是算错了，是告诉你方向反了：本来规定“吸收为正”，算出来是负的，说明它在**往外送电**。

所以它发出 10 W。
:::

::: muscle 薄肌秒杀
- 关联方向 → P = UI = −10 W < 0 → 发出。
- 别被负电压吓到，先乘再看符号。
- 考场速判：关联 + 负功率 = 电源；非关联 + 正功率 = 电源。
:::

## 二、计算题

### 1-3 {{基础}} {{8 分}}
三个电阻串联接在 12 V 电源上，R₁ = 2 Ω，R₂ = 3 Ω，R₃ = 7 Ω。求回路电流和各电阻电压。

::: answer 第 1-3 题 · 答案
R总 = 2 + 3 + 7 = 12 Ω  
I = 12 / 12 = 1 A  
U₁ = 2 V，U₂ = 3 V，U₃ = 7 V（校验：2+3+7 = 12 V）
:::

::: grandma 老奶解析
串联就像三个人排队过同一个闸口，水只能走一条路，所以电阻直接加起来：2 + 3 + 7 = 12 Ω。

总电压 12 V，总电阻 12 Ω，电流就是 12 ÷ 12 = 1 A。

每个电阻分到多少电压？用 U = IR 一个个算：2×1 = 2 V，3×1 = 3 V，7×1 = 7 V。

最后一定要验一下：三段加起来是不是等于总电压。等于，就对了。
:::

::: muscle 薄肌秒杀
- 串联：R总 = ΣR，I 处处相等，U 按阻值分。
- 三步：加电阻 → 求电流 → 逐个 U=IR。
- 陷阱：分压公式只在两个电阻时好用，三个以上直接算电流更快。
:::

### 1-4 {{进阶}} {{10 分}}
节点 a 连三条支路，电流分别为 I₁ = 3 A（流入）、I₂ = 5 A（流入）、I₃（流出）。用 KCL 求 I₃。

::: answer 第 1-4 题 · 答案
流入之和 = 流出之和：3 + 5 = I₃  
I₃ = 8 A
:::

::: grandma 老奶解析
节点就像十字路口的转盘，车不能停在里头。开进来 3 辆，又开进来 5 辆，一共 8 辆，那开出去也只能是 8 辆。

所以 I₃ = 3 + 5 = 8 A。
:::

::: muscle 薄肌秒杀
- KCL：ΣI流入 = ΣI流出。
- 遇到“流入/流出”混着标，先统一符号再代数求和。
- 陷阱：别把方向标反了还硬算，负号会告诉你标反了。
:::

### 1-5 {{拔高}} {{12 分}}
一个含两个独立源和三个电阻的线性网络，要求负载 R_L 上的电流。说明用戴维南定理求解的完整步骤，并写出最终表达式。

::: answer 第 1-5 题 · 答案
1. 断开 R_L，求端口开路电压 Uoc。  
2. 独立源置零（电压源短路、电流源开路），求端口等效电阻 Req。  
3. 画出戴维南等效电路：Uoc 串联 Req，再接 R_L。  
4. I_L = Uoc / (Req + R_L)。
:::

::: grandma 老奶解析
整个复杂网络，对 R_L 来说，其实只表现为“一个电池 + 一个内阻”。

第一件事：把 R_L 拔掉，量一下两个端点之间还有多高的电压，这就是 Uoc。

第二件事：把所有电源关掉——电压源当导线，电流源当断开——再从两个端点看进去，量出内阻 Req。

最后把 R_L 接回去，就是一个电池串一个电阻再串你的负载，电流自然是 Uoc ÷ (Req + R_L)。
:::

::: muscle 薄肌秒杀
- 口诀：**拔负载求开路电压，杀源求内阻。**
- 杀源：电压源短路、电流源开路；受控源必须保留。
- 含受控源时 Req 用外加电源法，不能直接串并联。
- 陷阱：Uoc 的极性决定最终电流方向，别只算大小。
:::

# 第 2 章 等效变换 | 本章一句话：戴维南一砍，半边电路直接下班，喔~可以耍起了耶。

{{高频}} {{3 题}} {{建议 30 分钟}}

## 一、计算题

### 2-1 {{基础}} {{8 分}}
两个电阻 R₁ = 6 Ω、R₂ = 3 Ω 并联，求等效电阻。

::: answer 第 2-1 题 · 答案
R = (6 × 3) / (6 + 3) = 2 Ω
:::

::: grandma 老奶解析
并联就像开了两个闸口，水走得更顺，所以总电阻一定比最小的那个还小。

两个电阻并联有个快公式：**积除以和**。6×3 = 18，6+3 = 9，18÷9 = 2 Ω。

验一下：2 Ω 比 3 Ω 还小，合理。
:::

::: muscle 薄肌秒杀
- 两电阻并联：R = R₁R₂/(R₁+R₂)。
- 速算：6 和 3 → 2（因为 6/3 = 2 倍关系，直接取小的那个的 2/3）。
- 陷阱：三个以上并联用 1/R = Σ1/R，别硬套两两公式。
:::

### 2-2 {{进阶}} {{10 分}}
某含源二端网络开路电压 Uoc = 12 V，等效内阻 Req = 4 Ω，接上可调负载 R_L。求 R_L 取何值时获得最大功率，并求该功率。

::: answer 第 2-2 题 · 答案
R_L = Req = 4 Ω  
Pmax = Uoc² / (4Req) = 144 / 16 = 9 W
:::

::: grandma 老奶解析
电源自己有内阻，就像水塔到你家之间的管道也有阻力。负载太小，电流大但电压被内阻吃掉了；负载太大，电压够了但电流又太小。

最划算的点在中间：**负载电阻 = 内阻**。

这时功率是 Uoc² ÷ (4Req) = 12² ÷ (4×4) = 144 ÷ 16 = 9 W。
:::

::: muscle 薄肌秒杀
- 最大功率传输：R_L = Req，Pmax = Uoc²/(4Req)。
- 识别信号：题目出现“可调负载”“最大功率”。
- 陷阱：这只对纯电阻负载成立；含电抗时要共轭匹配。
:::

### 2-3 {{拔高}} {{12 分}}
含受控源的二端网络，求戴维南等效电阻时为什么不能直接“电压源短路、电流源开路”？应改用外加电源法，具体怎么做？

::: answer 第 2-3 题 · 答案
受控源的输出依赖于电路中的电压/电流，电源置零会让控制量消失，等效关系被破坏，所以不能直接置零。

正确做法（外加电源法）：
1. 保留所有受控源，独立源置零。
2. 在端口外加电压 U（或电流 I）。
3. 求端口电流 I（或电压 U）。
4. Req = U / I。
:::

::: grandma 老奶解析
独立源像“自来水厂”，关掉就真没了，所以可以当它不存在。

受控源像“声控灯”：它自己不发电，但只要周围还有声音（控制量），它就会亮。你把电源全关了，控制量也没了，灯就不亮了——这跟真实工作时不一样。

所以不能直接关。要保留受控源，在门口自己加一个电压，看流进去多少电流，两者一除就是内阻。
:::

::: muscle 薄肌秒杀
- 受控源 = 依赖控制量的源，**不能置零**。
- 外加电源法：独立源置零 → 端口加 1 V → 求 I → Req = 1/I。
- 陷阱：控制量可能在被“砍掉”的另一半电路里，先确认控制量还在。
:::
