## 三个必须记住的约定

- 电压的“+”和“−”是**人为标的参考方向**，不是真实正负。
- 电流从“+”流入，叫**关联参考方向**；算出来是负数，说明真实方向和标的相反。
- 功率 P = UI：关联方向下 P>0 是**吸收**，P<0 是**发出**。

::: overview 本章速览
- 分值：约 18 分，必考

- 最省时解法：节点电压法，三步列方程

## 1.1 电压、电流、功率

::: grandma 老奶版
把电路想成**小区的水管**。

水压就是**电压**：水塔越高，压得越狠。水流就是**电流**：一秒钟流过多少水。

水龙头关着，水压还在，只是没有水流——所以**有电压不一定有电流**，但没有电压，水绝对不会自己往高处流。

功率就是**水电站发了多少电**：压力和流量乘起来。水压大、流量也大，干活才多。
:::

::: muscle 薄肌版
- 电压 = 电位差，单位 V；电流 = 电荷定向移动速率，单位 A。
- 参考方向随便标，算出来负号就是“反了”，别改方程，改解释。
- P = UI，关联参考方向下 P>0 吸收、P<0 发出。**负号不是算错，是物理事实。**
- 常见送分题：给 U、I 求功率，再问“吸收还是发出”。看到负号就答“发出”。
:::

### 1.1.1 参考方向（最容易丢分的地方）

::: warn 坑在这
参考方向和真实方向**没有关系**。题目给的箭头只是记账用的正方向，就像你记账时规定“收入为正”，结果这个月是负数，不代表收入这个东西不存在。
:::

## 1.2 基尔霍夫定律

::: key 一句话版本
KCL：**一个节点不存电**，流进来多少就得流出去多少。  
KVL：**绕一圈回到原点，电势不能凭空变**，升多少就得降多少。
:::

### KCL 的标准写法

1. 标出所有支路电流的参考方向。
2. 对节点写：流入之和 = 流出之和。
3. 或者统一写成“流出取正、流入取负”，代数和为 0。

> 考场提示：KCL 的方程个数 = 独立节点数 = n − 1。写了 n 个方程，必有一个是废的。

### KVL 的标准写法

| 情况 | 符号处理 |
| --- | --- |
| 沿绕行方向从“+”到“−” | 电压取正 |
| 沿绕行方向从“−”到“+” | 电压取负 |
| 遇到电压源 | 先看极性，再套上面两条 |

# 第 2 章 电阻电路的等效变换 | 本章是“把复杂电路揉成一个电阻”的手艺

{{高频}} {{1 题/年}}

::: overview 本章速览
- 分值：约 12 分，高频
- 核心：串并联、戴维南、最大功率传输
- 最省时解法：拔负载求开路电压，杀源求内阻
- 学完能做到：把一个三电阻网络化成一条支路
- 建议用时：50 分钟
:::

## 2.1 串联与并联

::: grandma 老奶版
串联就是**排队走一条路**：前面的人堵住，后面的人都得等，所以电阻越串越大。

并联就是**开了好几个闸口**：路越多越好走，所以电阻越并越小，而且总比最小的那个还小。
:::

## 2.2 戴维南定理

::: muscle 薄肌版
任何线性含源二端网络，对外都能等效成一个电压源 Uoc 串一个电阻 Req。

- Uoc：把负载**拔掉**，量开路电压。
- Req：把独立源**全部置零**（电压源短路、电流源开路），从端口看进去的等效电阻。
- 一句话：**先拔负载求开路电压，再杀源求内阻。**
:::

::: tip 秒杀顺序
求某条支路电流 → 先把这条支路以外的部分做戴维南 → 再串上负载算 I = Uoc/(Req+R)。  
比列一堆方程快得多，而且不容易错符号。
:::
