# 题库：去重、编排、双解析

速通题库不是"题越多越好"，是"每道题都代表一个还没被覆盖的考点"。

---

## 一、选题五条硬规则

### 1. 按考点去重，不按题干去重

同一道题换个数字、换个元件名，**算重复**。判定标准：

| 两题的关系 | 是否算重复 |
| --- | --- |
| 同一公式，只换数字 | 重复，留一题 |
| 同一方法，换情境（电路→生活） | 重复，留更接近真题的那题 |
| 同一考点，换题型（选择→计算） | 不重复，可各留一题 |
| 同一章，不同考点 | 不重复 |
| 同一题的不同小问 | 算一题，不拆开 |

**每道题在草稿里标注一个"考察点 ID"**（如 `KCL-符号`、`戴维南-开路电压`）。ID 相同只留一题。

### 2. 覆盖矩阵

先画表，再选题：

| 章节 | 选择 | 填空 | 计算/简答 | 综合 |
| --- | --- | --- | --- | --- |
| 第 1 章 | ✔ | ✔ | ✔ | |
| 第 2 章 | | ✔ | ✔ | ✔ |

- 每个"✔"至少一题；没有 ✔ 的格子说明这章没覆盖到。
- 题型按材料里的真实题型来，不硬造。材料只有计算题，就不要凑选择题。

### 3. 题源优先级

```
历年真题 > 老师作业/小测 > PPT 例题 > 教材课后题 > AI 改编
```

- 真题原题优先，最多改数字。
- 作业题优先保留，因为老师大概率按同一套路出。
- AI 自编题只用来补覆盖空洞，且必须标 `{{AI补充}}`。

### 4. 难度配比

速通以"能拿分"为目标，比例建议：

- 基础 40%（直接套公式）
- 进阶 40%（两步以上、带一个干扰条件）
- 拔高 20%（综合两章、逆向问）

每题的难度标在题号后：`{{基础}}` / `{{进阶}}` / `{{拔高}}`。

### 5. 可解性

- 条件必须完整，不能"略去次要因素"了还让人算。
- 数值题必须能算出干净结果（除非真题本来就很脏）。
- 图必须能复原：材料里的图如果关键，用文字把图和参数描述清楚，或注明"原图见 PPT 第 N 页"。
- 有图的题优先配原图，流程见第七节。
- 答案必须自己验算一遍。算不出来就换题。
- **配图不能带答案痕迹**：红笔标注、结论箭头、写好的数值都要裁掉。无答案版尤其如此。

---

## 二、题量控制

读者只有几个小时，题库总量按"2 小时能做完"控制：

| 总时长 | 题量 | 每章 |
| --- | --- | --- |
| 4 小时 | 12–16 题 | 2–3 题 |
| 6 小时 | 18–24 题 | 3–4 题 |
| 8 小时+ | 24–32 题 | 4–6 题 |

标「了解 / 不考」的章节 1–2 题即可；标「必考」的章节 5–6 题。

---

## 三、章节开头的一句话（带「耍起」）

题库的每一章开头必须有：

```
# 第 1 章 电路定律 | 本章一句话：先把 KCL 写对，你才有资格耍起。
```

要求：

- **一句话说清本章在干什么**，不是目录复述。
- 可以带「耍起」梗，每章最多一次；短课程全书 2–3 次就够。
- 不解释梗。
- 语气可以松，信息不能空。

示例：

- 「本章一句话：电压电流先分清，不然耍起的是自己。」
- 「本章一句话：戴维南一砍，半边电路直接下班，喔~可以耍起了耶。」
- 「本章一句话：三要素法三步走完，这章就通关，可以耍起。」
- 「本章一句话：概率这章只考你会不会分组，分对了就耍起。」
- 「本章一句话：别背公式，先看懂谁在推谁。」

## 四、无答案版结构

```markdown
---
title: 电路原理 · 通关题库（无答案）
subtitle: 按章节推进，做完一章划掉一章
course: 电路原理
track: 题目版
date: 2026-06-20
footer: 题库 · 无答案版
---

# 第 1 章 电路定律 | 本章一句话：……

{{必考}} {{6 题}} {{建议 40 分钟}}

## 一、选择题

### 1-1 {{基础}} {{3 分}}
题干……

A. ……
B. ……
C. ……
D. ……

## 二、计算题

### 1-4 {{进阶}} {{10 分}}
题干……
```

规则：

- **绝不出现答案、提示、解析**，连"显然"都不要。
- 题号用 `章-序`（1-1、1-2），方便答案版对应。
- 每题标难度和分值（分值按真题结构估）。
- 章末可放一句「学完能做到：独立做对 1-3、1-5」。
- 不要放答题横线（Word 里留白即可）。

## 五、答案版结构

题目部分与无答案版**完全一致**（同题号、同题干），解析紧跟在每题后面。

```markdown
### 1-1 {{基础}} {{3 分}}
题干……

::: answer 第 1-1 题 · 答案
**B**
:::

::: grandma 老奶解析
这题问的是……你可以把它想成……所以选 B。
关键：电压和电流的参考方向是两回事。
:::

::: muscle 薄肌秒杀
考点：关联参考方向下功率符号。
步骤：① 判关联 ② P=UI ③ 看正负。
陷阱：负号不代表算错，代表发出。
:::
```

### 解析双写规范

| 版本 | 写什么 | 不写什么 |
| --- | --- | --- |
| 老奶解析 | 为什么这么做、这个式子在人话里是什么 | 跳步、术语堆叠 |
| 薄肌解析 | 考点、三步内步骤、陷阱、考场信号 | 长篇原理、历史 |

**计算题**：

- 答案块给最终结果 + 关键中间量。
- 老奶解析讲"第一步为什么要这么设"。
- 薄肌解析给"标准步骤 ①②③ + 最容易错的那一步"。

**简答/论述题**：

- 答案块给"得分点清单"，每条一行。
- 老奶解析讲"这句话为什么能得分"。
- 薄肌解析给"必须出现的关键词"。

**证明题**：

- 答案块给完整证明（速通也要完整，证明题没有过程分就是 0）。
- 老奶解析讲"从哪句话入手"。
- 薄肌解析给"入口定理 + 关键变形"。

## 六、生成前自检

- [ ] 每道题都有唯一考察点 ID，且没有两个 ID 相同。
- [ ] 覆盖矩阵每个 ✔ 都有题。
- [ ] 无答案版全文搜索不到"答案""解析""故选"。
- [ ] 答案版题号与无答案版一一对应，数量一致。
- [ ] 每题都自己算过一遍，结果一致。
- [ ] 每章开头有一句话，且「耍起」没有超量。
- [ ] 难度标注齐全，配比接近 4:4:2。
- [ ] 没有把 PPT 原题整页照抄（除真题外，至少改数字/情境）。

## 七、配图流程

```
_extract/图索引.md
  ├─ slides/<文件名>/slide-05.png   ← PPT 整页，保真最高
  ├─ images/<文件名>/s05_image1.png ← PPT 里的原图
  ├─ images/<文件名>/p003_img2.png  ← PDF 内嵌图
  └─ pages/<文件名>/p003.png        ← PDF 整页（矢量图只能这样拿）
```

1. 先看 `图索引.md` 的“页面文字”列，按题干关键词找到对应页，再确认图。
2. 先跑 `crop_image.py --grid` 生成带 10% 网格的参考图，读准坐标后再裁，去掉页眉页脚和答案标注。
3. 优先用内嵌原图（清晰）；原图缺坐标轴、箭头时退回整页裁切。
4. 裁完自己再看一眼：题干里的数字、符号、方向箭头必须都在，且和题目一致。
5. 同一张图被多题共用，只在第一题插一次，后面写"同上图"。

```bash
python ~/.claude/skills/final-cram/scripts/crop_image.py \
  --src _extract/slides/第3章/slide-12.png \
  --box 8%,18%,94%,62% --out _source/fig/q3-2.png
```

**无答案版的图不能带答案**：老师讲评过的 PPT 常有红笔、结论箭头、写好的数字，裁掉或换一页。
