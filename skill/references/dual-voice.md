# 双轨讲解规范：老奶版 / 薄肌版

同一套知识点，写两遍。不是"一稿改语气"，而是两种不同的信息结构。

---

## 共同底线（两版都必须遵守）

1. **正确性优先于顺口。** 比喻可以糙，结论不能错。
2. **每个公式必须有适用条件。** 没条件的公式一律视为错。
3. **材料没有的内容标 `（AI补充）`。** 不把 AI 的猜测伪装成老师原话。
4. **不编造考点。** 不确定是否考，就写"材料未明确，按常考处理"。
5. **每个知识点都要落到"考试怎么用"。** 只讲概念不给用法，等于没讲。
6. **术语第一次出现必须给中文解释。** 英文缩写给全称 + 中文。
7. **公式用 Unicode 文本，不用 LaTeX。** 例：`U = IR`、`P = UI`、`∫f(x)dx`、`x²`、`√`、`≈`、`≤`。
8. **一段只讲一件事。** 中文长句拆短。

---

## 老奶版：我奶奶都能听懂

**读者画像**：完全零基础，上课没听，看到符号就划走，只剩几个小时。

### 五条硬规则

1. **先给生活画面，再给名字。** 顺序永远是：现象 → 直觉 → 术语。
2. **一句话一个意思，主句不超过 25 字。** 不用"由于……从而……进而……"。
3. **符号必须读出来。** 不写"由 KVL 得"，写"沿着回路走一圈，电压升多少就得降多少，这叫 KVL"。
4. **允许不精确，但必须补一句"严格说"。** 先让人懂，再修正。
5. **每个知识点固定回答四问**：这是什么 / 为什么有它 / 怎么用 / 最容易错在哪。

### 固定骨架

```
::: grandma 老奶版
【打个比方】……（生活场景，3 句以内）
【所以它是】……（一句人话定义）
【严格一点说】……（教材定义，一句）
【考场上】看到……就先……（可执行动作）
:::
```

### 三类可用类比

| 抽象概念 | 生活画面 |
| --- | --- |
| 电压 / 电流 / 电阻 | 水压 / 水流 / 水管粗细 |
| 电容 / 电感 | 水库 / 惯性飞轮 |
| 反馈 / 稳态误差 | 空调温控 / 追公交 |
| 概率 / 条件概率 | 抽奖 / 已知中了奖再算 |
| 矩阵 / 秩 | 筛子 / 有效信息条数 |
| 极限 / 导数 | 逼近 / 瞬时速度 |
| 熵 / 信息量 | 惊喜程度 |

### 反例（不要这样写）

- ❌ "由基尔霍夫电压定律可知，沿任一闭合回路各支路电压代数和为零。"——术语堆叠，零信息。
- ❌ "显然，该矩阵满秩。"——"显然"是老奶版禁词。
- ❌ "宝子们，这个知识点超简单的哦～"——油腻，且不解决理解。
- ❌ 一段 150 字没有换行。

### 正例

> 把电路想成小区水管。水压就是电压，水塔越高压得越狠；水流就是电流，一秒流过多少水。
> 水龙头关着，水压还在，但没有水流——所以有电压不一定有电流。
> 严格说：电压是两点电位之差，电流是电荷的定向移动。
> 考场上看到"求某点电位"，先选一个参考点当 0，再一路减过去。

## 薄肌版：有基础，快速查漏补缺

**读者画像**：上过课、会基本运算、只想在几小时内把框架和套路装回脑子。

### 五条硬规则

1. **结论先行。** 第一句就是能直接用的结论，不铺垫。
2. **能表格不段落，能一行不两行。** 每节 bullet ≤ 5 条，超了就拆表。
3. **明确标"考 / 不考 / 怎么考 / 几步出答案"。**
4. **公式和条件成对出现。** 例："戴维南：仅线性网络；含受控源时 Req 用外加电源法。"
5. **允许吐槽题目，不允许吐槽读者。** 幽默是润滑剂，不是内容。

### 固定骨架

```
::: muscle 薄肌版
- 一句话：……
- 适用：…… / 不适用：……
- 步骤：① …… ② …… ③ ……
- 陷阱：……
- 考场信号：看到"……"直接上这招。
:::
```

### 语气标尺

- 可以："这题不考算我输。"
- 可以："看到'求最大功率'，条件反射写 R = Req，别多想。"
- 可以："教材这里绕了三页，其实就一句话。"
- 不可以："这么简单都不会？"
- 不可以：为玩梗牺牲条件（"直接秒"但没说适用范围）。

### 反例

- ❌ 把老奶版的比喻原样搬过来还加长。
- ❌ 只列公式不给触发条件。
- ❌ 一段里塞 8 个知识点，没有层级。

---

## 两版怎么配合

- **同一骨架，不同密度**：老奶版 1 个知识点 ≈ 120–200 字；薄肌版 ≈ 40–80 字或一张 3 行表。
- **薄肌版不重复老奶版已经讲透的直觉**，直接给"条件 + 步骤 + 陷阱"。
- **答案版解析双写**：老奶解析讲"为什么这么做"，薄肌解析讲"考场几步出答案 + 坑在哪"。
- 同一份文档只放一个版本；两版分成两个文件，不要混排。

## 「耍起」梗使用规范

用户自带的梗，原意：

> 喔~可以耍起了耶 / 诶~真的假的可以吗 / 那我也是直接耍起走了 / 耍起耍起耍起。
> 内核是：压力这么大，好好爱自己，人生苦短及时行乐。

**用法**：
- 每章开头一句主线总结里，最多用一次「耍起」。
- 每章最多一次，全书不超过章节数；宁可少，不要每段都来。
- 只用于"松弛、开局、通关庆祝"的语境，不用于安全警告、严肃结论、失败提醒。
- 保留"耍起"二字即可，句式可变化，不必每次抄全句。
- 不解释这个梗，读者懂就懂。

**示例**：
- 「本章一句话：先把 KCL 写对，你才有资格耍起。」
- 「第三章主线：三要素法三步走完，喔~可以耍起了耶。」
- 「这一章分值最高，学完再耍，不然耍的是自己。」
- 「本章一句话：戴维南一砍，半边电路直接下班，可以耍起了。」

**不要**：
- 每段都来一句「耍起」。
- 在"这题你大概率会错"后面接「可以耍起了」，语感打架。
- 把梗写进公式、答案结论、考试注意事项。
