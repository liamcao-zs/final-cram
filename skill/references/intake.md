# 摄取与边界：动手写之前必须做的事

速通最常见的失败不是讲错，是**讲了一堆不考的**。所以先定边界，再动笔。

---

## 一、材料角色判定

| 角色 | 识别信号 | 用法 |
| --- | --- | --- |
| 考纲 / 复习提纲 | 文件名含"大纲""考纲""范围" | **最高优先**，直接决定取舍 |
| 历年真题 / 模拟卷 | 含"真题""试卷""期末" | 定题型、定分值、定难度 |
| 平时作业 / 小测 | 含"作业""习题""quiz" | 定高频考点，优先选原题 |
| 老师 PPT | 文件名含"第X章"、页面多 | 定知识边界、看老师强调 |
| 教材 / 讲义 | 页数多、有目录 | 补定义和推导，**不要逐页读** |
| 笔记 / 学长资料 | 个人整理 | 只作补充，需与 PPT 交叉验证 |

**冲突处理**：考纲 > 真题 > 作业 > PPT > 教材。冲突处在边界卡里记一句。

---

## 二、提取

```bash
python ~/.claude/skills/final-cram/scripts/extract_materials.py \
  "资料文件夹" --out "期末速通_课程/_extract"
```

然后：

1. 先读 `提取/材料清单.md`，只花 1 分钟；配图素材看 `提取/图索引.md`。
2. 再读 `提取/text/*.md` 的**标题层**：所有 `#`、`## [p.N]`、`## [slide N]`。
3. 只在需要细节时读某一页的正文。
4. 清单里标了"低文本页/幻灯片"的，**必须用 Read 工具看图**，不能只读文本。
5. PPT 每页已用 PowerPoint 导成 PNG（`slides/`），PPT 里的图、公式、排版都能直接用；PDF 每页也已导出（`pages/`），矢量图从整页图里裁。

> 大文件不要一次性全读进上下文。先标题层，再定点深入。这是速通 skill 的省 token 纪律。

---

## 三、重建章节链路

大学课程是按章节递进的，所以顺序不能乱。从材料里抽出：

1. **章节列表**：以 PPT 的章标题 / 教材目录为准，作业题号做校正。
2. **每章的核心方法**：一章通常只教一个新方法（节点法、三要素法、贝叶斯……）。
3. **前置依赖**：这章用到了前面哪一章的结论。画成链：

```
第1章 基本定律 → 第2章 等效变换 → 第3章 动态电路
                        ↘ 第4章 正弦稳态（依赖第2章相量）
```

4. **可合并/可跳过**：如果某章在 PPT 里只有 3 页、作业没题、考纲没提，标"了解"。

**顺序原则**：默认按材料章节顺序。只有一种情况打乱——某章是纯工具章（如数学预备），把它插到第一次用到它的那一章前面，并注明"提前插入"。

## 四、学习边界卡

在写任何正文之前，先在对话里输出这张卡（同时存成 `00_边界卡.md`）：

```markdown
# 学习边界卡

## 1. 这次要拿多少分
- 目标：及格 / 70+ / 冲高分
- 可用时间：__ 小时
- 取舍原则：保 __ 章，放 __ 章

## 2. 纳入范围
- 章节：第 1–6 章
- 知识点：__ 个（必考 __ / 高频 __ / 了解 __）
- 题目：__ 题（真题 __ / 作业 __ / AI 补充 __）

## 3. 排除范围
- 第 7 章（PPT 只有 2 页，作业无题）→ 不看
- 第 3 章的推导证明 → 只记结论

## 4. 依据
- 考纲：有 / 无
- 真题：__ 套
- 作业：__ 份
- PPT：__ 份
- 缺口：__（哪部分材料缺失，用了什么替代）

## 5. 输出确认
- 笔记：老奶版 + 薄肌版
- 题库：无答案版 + 双解析答案版
- 命名与目录：__
```

**这张卡要能被用户一句话否决。** 输出后问一句"这个边界对吗？要增要减现在说"，然后按用户回复改。

## 五、向用户提问：只问一轮

默认只问 3 个问题，且每个都有默认值，用户说"你定"就直接用默认：

1. **考到哪、什么题型？**（默认：按 PPT 全部章节 + 作业出现的题型）
2. **还有几小时？**（默认：6 小时）
3. **哪几章最虚 / 老师有没有划重点？**（默认：按章节优先级自动排序）

不要问："你想要什么风格？"（规范已定）、"要不要加图？"（Word 四角已有）、"先做哪份？"（顺序已定）。

如果用户一开始就给了这些信息，**不要重复问**。

## 六、缺口与置信度

| 情况 | 处理 |
| --- | --- |
| 某章 PPT 缺失 | 用作业题反推考点，标 `（材料未覆盖，按作业推断）` |
| 扫描版 PDF 无文字 | 看图 + 手动转录关键页，标 `（OCR 缺失，已看图）` |
| 作业页有手写答案 | **不要用整页截图**，优先用页内内嵌原图；没有原图就裁掉手写区域 |
| 真题只有回忆版 | 按回忆版题型出题，标 `（真题为回忆版）` |
| 老师没划重点 | 按作业频次 + PPT 页数估，标 `（经验估计）` |
| 题目图缺失 | 用文字描述图，或注明"原图见 PPT 第 N 页" |

**原则**：宁可标"不确定"，不要编。编一个考点，读者会花两小时学它。

## 七、工作区结构

生成过程产生的中间文件放在同一个工作区，交付物放最外层：

```
期末速通_<课程>/
├── 00_边界卡.md
├── 01_速通笔记_老奶版.docx
├── 01_速通笔记_薄肌版.docx
├── 02_通关题库_无答案.docx
├── 03_通关题库_答案解析.docx
├── _source/              # 可重新渲染的 Markdown 源
│   ├── notes_grandma.md
│   ├── notes_muscle.md
│   ├── questions.md
│   └── answers.md
├── _extract/             # 提取结果（清单、文本、图片、缓存）
└── _preview/             # 验收用 PDF/PNG，可删
```

保留 `_source/` 很重要：用户想改一句话，重新跑渲染器即可，不用重生成。
