# Word 源文件规范与排版

三份交付物都由同一个渲染器生成，源文件是一种受控 Markdown（下文简称 FC-Markdown）。

---

## 一、源文件头（front matter）

```markdown
---
title: 电路原理 · 期末速通
subtitle: 6 小时，从"这是啥"到"这我会"
course: 电路原理
track: 老奶版
audience: 零基础 / 上课只记得老师姓什么
date: 2026-06-20
toc_depth: 1
footer: 期末速通 · 老奶版
accent: 1F4E5F
cover_note: 以题目为准，以得分为目标。
---
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| title | 是 | 封面主标题 |
| subtitle | 否 | 封面副标题 |
| course | 是 | 课程名 |
| track | 是 | 老奶版 / 薄肌版 / 题目版 / 答案版 |
| audience | 否 | 适用人群 |
| date | 是 | 生成日期，`YYYY-MM-DD` |
| toc_depth | 否 | 目录层级，`1`（只列章）或 `2`（章 + 节），默认 1 |
| page_break | 否 | `false` 时章标题不再强制分页，适合题库这类连续排版；默认 `true` |
| footer | 否 | 页脚右侧文字 |
| accent | 否 | 强调色，十六进制，默认 `1F4E5F` |
| cover_note | 否 | 封面底部一行小字 |

## 二、语法

| 写法 | 效果 |
| --- | --- |
| `# 第 1 章 标题 \| 一句话主线` | 一级标题，新起一页，进目录，加书签，`\|` 后为灰色主线句 |
| `## 1.1 小节` | 二级标题（toc_depth=2 时进目录） |
| `### 1.1.1 知识点` | 三级标题，不进目录 |
| `#### 小点` | 四级标题 |
| `**加粗**` | 加粗 |
| `R_{L}` | 下标（花括号内） |
| `x^{2}` | 上标（花括号内） |
| `*斜体*` | 斜体 |
| `` `代码` `` | 等宽红字 |
| `{{必考}}` | 标签胶囊。可用：必考 / 重点 / 高频 / 中频 / 易错 / 秒杀 / 了解 / 不考 |
| `- 条目` | 项目符号 |
| `  - 子条目` | 二级项目符号（缩进两个空格） |
| `1. 条目` | 编号列表 |
| `> 提示` | 左侧竖线引用块 |
| `---` | 细分隔线 |
| `A. 选项` | 单独成段的选择题选项（B/C/D 同理） |
| 行尾两个空格 | 段内强制换行 |
| `![图 1-1 电路图](相对路径.png)` | 居中插图 + 灰色图注，路径相对源文件 |
| 表格 | 第一行当表头，第二行 `\| --- \|` 会被忽略 |
| `::: grandma 老奶版` … `:::` | 提示框，见下 |

### 提示框类型

| 类型 | 颜色 | 用途 |
| --- | --- | --- |
| `overview` | 浅灰蓝卡片 | 章首「本章速览」 |
| `grandma` | 暖米色 | 老奶版讲解 |
| `muscle` | 浅青色 | 薄肌版讲解 |
| `tip` / `key` | 浅绿 | 要点、必记 |
| `warn` | 浅红 | 易错、坑 |
| `note` | 浅灰 | 一般提示 |
| `answer` | 浅蓝 | 答案块 |
| `summary` | 浅黄 | 章末收口 |

旧源文件里的 `::: boss` 会自动按「本章速览」渲染，但新内容一律用 `overview`，并且不要写游戏化措辞。

### 已知限制

1. **不支持 LaTeX。** 公式用 Unicode + 上下标：`U = IR`、`R_{L}`、`U_{oc}^{2}`、`e^{-t/τ}`、`√`、`≤`、`≈`、`∫`、`Σ`、`ω`、`τ`、`Δ`。花括号下标/上标只能是单层，不能嵌套。
2. **图片只能整段插入，不能行内。** 自动缩放到 15.4 cm 以内，小图不放大。
3. **表格不要嵌套。** 提示框里放表格不会渲染。
4. **提示框不要嵌套提示框。** 内外层只会保留一层。
5. **一级标题自动分页。** 不要把 `#` 当普通小标题用。
6. **`|` 是标题分隔符。** 标题里不要出现竖线。
7. **中文引号用“”，不要用 ASCII 的 `"`。** 数字和单位之间留空格：`12 V`、`3 A`、`2 Ω`。

### 配图从哪来

| 情况 | 做法 |
| --- | --- |
| PPT 整页 | 已由 PowerPoint 导成 `_extract/slides/<文件名>/slide-NN.png`，保真最高，优先从这里裁 |
| PPT 内嵌原图 | `_extract/images/<文件名>/sNN_imageK.*`，清晰但可能缺坐标轴/箭头 |
| PDF 内嵌位图 | `_extract/images/<文件名>/pNNN_imgK.*`，可直接用 |
| PDF 矢量图 / 扫描图 | 默认已导出全部整页（`pages/`），直接裁 |
| 题目共用一张图 | 只在第一题插一次，后续题写"同上图" |

`_extract/图索引.md` 里每张图都带“页面文字（前 60 字）”，先按题干关键词找到对应页，再裁。

```bash
B=~/.claude/skills/final-cram/scripts

# 1. 先生成带 10% 网格的参考图，肉眼读坐标
python $B/crop_image.py --src _extract/pages/hw/p003.png \
  --grid --out _source/fig/p003-grid.png

# 2. 再按百分比裁
python $B/crop_image.py --src _extract/pages/hw/p003.png \
  --box 8%,20%,92%,55% --out _source/fig/question-1-3.png
```

**原则**：有图就必须配图，尤其是电路、受力、几何、函数图像；没图就写清"原图见 PPT 第 N 页"，不要让学生自己猜。

**优先用内嵌原图**：扫描过、批注过、写过答案的页面，整页截图会把手写答案一起带进去；`images/` 里的内嵌原图通常是干净的。

## 三、三份文档的骨架

### 1. 速通笔记

```markdown
# 开篇 时间怎么花 | 这一页告诉你先学哪章、每章多久
（总览表：章节 / 重要度 / 一句话 / 建议用时 / 题号）

# 第 1 章 …… | 本章一句话……
{{必考}} {{3 题/年}}
::: overview 本章速览
- 分值 / 核心 / 最省时解法 / 学完能做到 / 建议用时
:::
## 1.1 ……
::: grandma 老奶版 …… :::
::: muscle 薄肌版 …… :::
## 1.x 本章速记卡
（3–6 行表格）
```

### 2. 题库（无答案）

```markdown
# 第 1 章 …… | 本章一句话：……
{{必考}} {{6 题}} {{建议 40 分钟}}

## 一、选择题
### 1-1 {{基础}} {{3 分}}
题干 + 选项
```

### 3. 题库（答案解析）

题目与无答案版完全一致，每题后接：

```markdown
::: answer 第 1-1 题 · 答案
**B**
:::
::: grandma 老奶解析
……
:::
::: muscle 薄肌秒杀
考点 / 步骤 / 陷阱
:::
```

## 四、排版参数（渲染器固定，供核对）

| 项目 | 值 |
| --- | --- |
| 纸张 | A4，上下 2.15 cm，左右 2.4 cm |
| 中文正文 | 微软雅黑 10.5 pt，行距 1.55，两端对齐 |
| 西文正文 | Calibri |
| 一级标题 | 17 pt 加粗，章前分页，底部强调线 |
| 二级标题 | 13 pt 加粗，强调色 |
| 三级标题 | 11 pt 加粗 |
| 表格 | 9.5 pt，表头浅灰底，无竖线 |
| 页脚 | 页码 / 总页数 + 自定义文字，8.5 pt |
| 四角水印 | 1.35 cm，34% 不透明度，距页边 0.4 cm |
| 目录 | 可点击，章级 + 节级（可选），章后带一句话 |

## 五、生成与验收

```bash
B=~/.claude/skills/final-cram/scripts

# 0. 结构自检（题号、答案泄漏、缺图、两版对齐）
python "$B/check_docs.py" \
  --questions _source/questions.md --answers _source/answers.md \
  --grandma _source/notes_grandma.md --muscle _source/notes_muscle.md \
  --base-dir _source

# 1. 生成
python $B/build_docx.py --src _source/notes_grandma.md --out 01_速通笔记_老奶版.docx

# 2. 验收（导出 PDF + PNG）
python $B/verify_docx.py --src 01_速通笔记_老奶版.docx --out-dir _preview
```

验收时逐页看图，重点看：

- [ ] `check_docs.py` 没有 FAIL（警告可人工判断）
- [ ] `verify_docx.py` 没有标“空白页/近空白页”
- [ ] 封面没有错位，元信息两列对齐
- [ ] 目录条目数量 = 章数（或章 + 节），点击能跳
- [ ] 每章开头的「本章速览」完整，没有跨页断裂
- [ ] 表格没有只剩一行的孤行
- [ ] 四角水印没有压住正文
- [ ] 页脚页码连续
- [ ] 没有空白页（`verify_docx.py` 会标"空白页?"）

> 验收脚本依赖本机 Word（COM 导出 PDF）。没有 Word 时跳过，直接看 .docx 文件大小和 XML 是否正常。
