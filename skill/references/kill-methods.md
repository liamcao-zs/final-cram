# 秒杀招式库

速通的核心不是"懂原理"，是"看到题能三步内出答案"。下面是按学科整理的常用招式。

**使用纪律（先读）**

1. **每招必须带适用条件。** 不写条件的秒杀法 = 错误答案。
2. **材料里老师给的方法优先。** 老师的方法即使笨，也是判卷标准。
3. **网络流传的"秒杀"必须自己验一遍。** 用一道课后题代入，对不上就不写。
4. **秒杀只用于选择/填空和结果校验。** 大题仍要写关键步骤，否则没过程分。
5. **不确定时给常规解法。** 宁可多两步，不要错。

## A. 通用四板斧（所有学科）

| 招式 | 触发 | 做法 | 边界 |
| --- | --- | --- | --- |
| 特殊值 | 选择题、恒等式 | 代 0、1、∞ 或对称点 | 只能排除，不能证明 |
| 量纲检验 | 物理/电路公式 | 看单位是否对得上 | 无量纲结论无效 |
| 对称性 | 积分、电路、场 | 奇函数积分为 0；对称电路等电位 | 先确认对称轴 |
| 极限情形 | 参数题 | 令参数趋 0 或 ∞ 看退化结果 | 只作校验 |

## B. 高等数学

### B1. 等价无穷小（x→0）

```
sin x ~ x      tan x ~ x      arcsin x ~ x     arctan x ~ x
1 - cos x ~ x²/2              ln(1+x) ~ x
e^x - 1 ~ x                   (1+x)^a - 1 ~ ax
```

- **适用**：乘除因子替换。
- **不适用**：加减法中直接替换（会丢主项）。加减先通分或提公因式。
- **典型坑**：`sin x - x` 不能换成 `x - x = 0`，要用泰勒到三阶：`-x³/6`。

### B2. 洛必达

- **触发**：0/0 或 ∞/∞。
- **步骤**：确认型 → 分子分母分别求导 → 再看极限。
- **边界**：分子分母在去心邻域可导且分母导数不为 0；导数之比的极限存在或为 ∞。
- **坑**：不是 0/0 型硬用；用了之后震荡（如 x→∞ 时 sin x）说明该换方法。

### B3. 泰勒展开阶数怎么定

- 分子分母谁先"消掉"就到谁为止。
- 常见：`e^x = 1+x+x²/2+x³/6+…`，`ln(1+x)=x-x²/2+x³/3-…`，`sin x = x-x³/6+…`，`cos x = 1-x²/2+x⁴/24-…`。
- **口诀**：上限比下限多展一阶，防止主项被减没。

### B4. 分部积分顺序 LIATE

对数 → 反三角 → 代数 → 三角 → 指数，**排前面的当 u**。

```
∫ x e^x dx：u = x，dv = e^x dx
∫ x ln x dx：u = ln x，dv = x dx
```

- **边界**：凑不出 dv 就换思路（换元/拆项）。

### B5. 定积分的对称与周期

- `f` 为奇函数：`∫_{-a}^{a} f = 0`。
- `f` 为偶函数：`∫_{-a}^{a} f = 2∫_0^a f`。
- 周期 T：`∫_a^{a+T} f = ∫_0^T f`。
- **墙函数**：`∫_0^{π} x f(sin x) dx = (π/2)∫_0^{π} f(sin x) dx`。

### B6. 旋转体体积

- 绕 x 轴（圆盘）：`V = π∫_a^b y² dx`。
- 绕 y 轴（柱壳）：`V = 2π∫_a^b x·f(x) dx`。
- **坑**：先画图确认谁是外半径、谁是内半径；有小孔要相减。

### B7. 级数判敛顺序

```
通项不趋 0 → 发散
↓
p 级数 / 几何级数 → 直接判
↓
比值法（含阶乘、指数）→ 根值法（含 n 次方）
↓
比较 / 极限比较 → 莱布尼茨（交错）
```

- **坑**：比值法极限 = 1 时失效，换比较法。

### B8. 常系数非齐次特解设法

| 右端 f(x) | 特解形式 |
| --- | --- |
| `P_n(x)` | `Q_n(x)`，若 0 是特征根乘 x^k |
| `e^{ax}P_n(x)` | `e^{ax}Q_n(x)`，a 是 k 重根乘 x^k |
| `e^{ax}(A cos bx + B sin bx)` | 同型，a±bi 是根乘 x |

- **口诀**：右端长什么样，特解就长什么样；撞根就乘 x。

## C. 线性代数

### C1. 特征值速算

- `Σλ = tr(A)`，`Πλ = det(A)`。
- 三角矩阵特征值 = 对角线。
- `A` 的特征值是 λ，则 `A^{-1}` 是 1/λ，`A²` 是 λ²，`A+kI` 是 λ+k。
- **用途**：选择题不用解特征方程。

### C2. 秩与解的结构

- `r(A) = r(A|b)` 有解；`= n` 唯一解；`< n` 无穷多解。
- 基础解系个数 = `n - r(A)`。
- **口诀**：秩 = 有效方程数；自由变量 = 未知数 − 有效方程。

### C3. 正定判定

- 顺序主子式全 > 0 ⇔ 正定。
- 特征值全 > 0 ⇔ 正定。
- **坑**：只验 `det(A) > 0` 不够。

### C4. 相似对角化

- n 个线性无关特征向量 ⇔ 可对角化。
- 实对称矩阵一定可正交对角化。
- **速判**：特征值互异 → 一定可对角化。

## D. 概率论

### D1. 全概率 / 贝叶斯

- 全概率：按"原因"分组，`P(B) = ΣP(A_i)P(B|A_i)`。
- 贝叶斯：已知结果反推原因，`P(A_i|B) = P(A_i)P(B|A_i) / P(B)`。
- **识别**：题目出现"已知……求……是哪个原因"。

### D2. 期望方差速算

```
E(aX+b) = aE(X)+b
Var(aX+b) = a²Var(X)
E(X+Y) = E(X)+E(Y)              （无需独立）
Var(X+Y) = Var(X)+Var(Y)+2Cov     （独立时交叉项为 0）
```

- **坑**：`E(XY)=E(X)E(Y)` 只在独立时成立。

### D3. 常见分布

| 分布 | E | Var |
| --- | --- | --- |
| B(n,p) | np | np(1-p) |
| P(λ) | λ | λ |
| U(a,b) | (a+b)/2 | (b-a)²/12 |
| E(λ) | 1/λ | 1/λ² |
| N(μ,σ²) | μ | σ² |

### D4. 正态标准化

`X~N(μ,σ²) → Z=(X-μ)/σ ~ N(0,1)`，查表用 Φ。

- **坑**：`Φ(-z) = 1-Φ(z)`，别查错方向。

## E. 电路

### E1. 节点电压法

1. 选参考节点（接地，电位 0）。
2. 对其余节点列 KCL：自导 × 本节点电压 − 互导 × 邻节点电压 = 注入电流。
3. 解方程。

- **边界**：含电压源时，把电压源一端设为参考，或引入超节点。
- **考场信号**：节点数 ≤ 3 时，永远优先节点法。

### E2. 网孔电流法

- 网孔数 < 节点数 − 1 时用。
- 自阻 × 本网孔电流 − 互阻 × 邻网孔电流 = 本网孔电压源代数和。
- **坑**：电流源在公共边时引入超网孔。

### E3. 叠加定理

- 每个独立源单独作用，其余电压源短路、电流源开路，结果相加。
- **边界**：只适用于线性量（电压、电流）。**功率不能叠加**，必须用总电压/总电流再算。

### E4. 戴维南 / 诺顿

- `Uoc`：负载断开，求开路电压。
- `Req`：独立源置零，从端口看进去；含受控源时用外加电源法（加 1V 求 I，或加 1A 求 U）。
- 诺顿：`Isc = Uoc/Req`，`Req` 并联。
- **考场信号**：只求一条支路的量 → 戴维南。

### E5. 最大功率传输

- 负载 `R_L = Req` 时功率最大，`Pmax = Uoc²/(4Req)`。
- **边界**：只对可调纯电阻负载成立。

### E6. 一阶电路三要素法

```
f(t) = f(∞) + [f(0+) - f(∞)] e^{-t/τ}
```

1. 求初始值 `f(0+)`：换路前稳态 + 换路定则（电容电压、电感电流不跃变）。
2. 求稳态值 `f(∞)`：换路后直流稳态（电容开路、电感短路）。
3. 求时间常数 `τ`：`τ = RC` 或 `τ = L/R`，R 是从储能元件两端看进去的等效电阻。

- **坑**：`f(0+)` 不是换路前的值，要先算换路前稳态再套定则。

### E7. 相量法

- 正弦量 → 相量，阻抗 `Z_R=R`，`Z_L=jωL`，`Z_C=1/(jωC)`。
- 之后全按直流电阻电路算，最后反变换。
- **边界**：仅同频率正弦稳态。

### E8. 谐振

- 串联谐振：`ω₀=1/√(LC)`，阻抗最小、电流最大。
- 并联谐振：阻抗最大。
- 品质因数 `Q = ω₀L/R`。

## F. 大学物理

### F1. 动量 / 能量二选一

- 碰撞、爆炸、反冲 → 动量守恒（合外力为零）。
- 有摩擦生热、弹簧、高度 → 能量守恒（注意非保守力做功）。
- **口诀**：只问速度用动量，问高度/热量用能量。

### F2. 刚体转动

- `M = Iβ`，`L = Iω`，`E_k = ½Iω²`。
- 平行轴定理：`I = I_c + md²`。
- **坑**：绳绕滑轮，绳两端张力不等，差值提供力矩。

### F3. 高斯定理

- `∮E·dS = Q_内/ε₀`。
- 只对球、柱、面对称好用；先判对称性再选高斯面。
- **坑**：高斯面外的电荷不影响通量，但影响场强。

### F4. 安培环路 / 法拉第

- `∮B·dl = μ₀I_内`。
- `ε = -dΦ/dt`，方向用楞次定律（阻碍磁通变化）。
- **口诀**：先算磁通，再求导，最后定方向。

## G. 自动控制 / 信号（工科专业课）

### G1. 拉氏变换常用对

```
1 ↔ 1/s            t ↔ 1/s²           e^{-at} ↔ 1/(s+a)
sin ωt ↔ ω/(s²+ω²)  cos ωt ↔ s/(s²+ω²)
t^n ↔ n!/s^{n+1}    e^{-at}sin ωt ↔ ω/((s+a)²+ω²)
```

- **位移定理**：乘 `e^{-at}` ↔ s 换成 s+a。
- **微分定理**：`f' ↔ sF(s)-f(0)`。

### G2. 终值定理

- `lim_{t→∞} f(t) = lim_{s→0} sF(s)`。
- **边界**：`sF(s)` 的极点必须全在左半平面（含原点一阶）。不稳定系统不能用。
- **坑**：有右半平面极点时算出来是数，但物理上发散。

### G3. 梅森增益公式

```
G = Σ P_k Δ_k / Δ
```

- `P_k`：第 k 条前向通路增益。
- `Δ = 1 - ΣL_i + ΣL_iL_j - …`（不接触回路）。
- `Δ_k`：去掉与第 k 条通路接触的回路后的 Δ。

### G4. 劳斯判据

1. 列劳斯表。
2. 第一列符号变化次数 = 右半平面极点数。
3. 稳定 ⇔ 第一列全正。

- **特例**：出现全零行，用上一行系数构造辅助方程求导；首列出现 0，用 ε 代替。

### G5. 根轨迹速画

- 起点：开环极点；终点：开环零点（含无穷远）。
- 分支数 = `max(n, m)`。
- 实轴上：右侧实数开环零极点个数为奇数的区段在轨迹上。
- 渐近线：角度 `(2k+1)180°/(n-m)`，交点 `(Σp-Σz)/(n-m)`。
- 分离点：`dK/ds = 0`。

### G6. 伯德图判稳

- 截止频率 `ω_c`：`|G(jω_c)| = 1`（0 dB）。
- 相位裕度 `γ = 180° + ∠G(jω_c)`。
- 增益裕度 `K_g = 1/|G(jω_g)|`，`ω_g` 是相位 −180° 处。
- **口诀**：相位裕度看截止，增益裕度看穿越。

## H. 文科 / 记忆类（速通变体）

不是所有课都能"秒杀"。文科类用下面三招：

1. **关键词锚定**：每个知识点只背 3 个判卷关键词，答题时先写关键词再展开。
2. **时间轴 / 因果链**：把章节压成"因为 A → 所以 B → 导致 C"的一条线。
3. **对比表**：易混概念两两列表，只记差别项。

**答题模板**：定义 → 背景/原因 → 内容/特点 → 影响/意义。四段各一句，先拿结构分。
