# 学科打法：四套模板，别用一种声音讲所有课

同样是速通，高数、电路、思政、法学的"会"不是一个意思。先选模板，再动笔。

| 模板 | 典型课程 | 核心产物 | 题目形态 |
| --- | --- | --- | --- |
| 理科计算 | 高数、线代、概率、大学物理 | 公式条件 + 三步解法 | 计算、证明 |
| 工科专业 | 电路、自控、信号、材力 | 模型 + 步骤 + 校验 | 计算、分析 |
| 文科记忆 | 思政、历史、法学理论 | 必背表述 + 关键词对应 | 选择、判断、简答、论述 |
| 医学 / 法学案例 | 诊断学、民法、刑法 | 临床/法律关系链 + 要件 | 案例、简答 |

选错模板的后果：用理科那套讲思政，会写出一堆正确但考不到的废话；用文科那套讲电路，会背了一堆定义但不会算。

---

## 一、理科计算

- 每章速览字段：核心公式、适用条件、三步解法、学完能做到、建议用时。
- 讲解重点：**这个公式什么时候不能用**。只写公式不写条件，等于埋雷。
- 题目：优先材料原题；答案必须有完整步骤和量纲/合理性校验。
- 秒杀招式从 [kill-methods.md](kill-methods.md) 取，但必须标适用条件。

## 二、工科专业

- 每章速览字段：物理模型、方程、求解步骤、工程校验。
- 讲解重点：**建模 → 方程 → 求解 → 校验**四段式。
- 题目：图必须配；含受控源、非线性、时变等条件必须写全。
- 答案模板：
  ```
  建模：把题变成什么方程
  列式：依据哪条定律
  求解：①②③
  校验：单位/量级/极限情形
  ```

## 三、文科记忆（思政、历史、法学理论）

这是最容易被理科模板带偏的一类。按下面这套走。

### 章节结构

```markdown
# 第 X 章 标题 | 一句话主线

{{必考}} {{选择题高频}} {{建议 8 分钟}}

::: overview 本章速览
- 考法：选择题为主 / 简答论述
- 核心：本章 3–5 个高频表述
- 答题结构：定义 → 背景 → 内容 → 意义
- 学完能做到：看到关键词能选对，大题能列 3 点
- 建议用时：8 分钟
:::

## 必背
1. 原文表述（越接近原话越好）
2. ……

::: grandma 老奶版
生活化解释，控制在 3 段以内
:::

## 易混
| 提法 | 答案 |
| --- | --- |

## 30 秒自测
一句话问题 + 括号答案
```

### 关键词提词器（必备）

文科选择题大半考"固定搭配"。全书最后加一页：

| 题干关键词 | 对应答案 |
| --- | --- |
| 最本质的特征 | 党的领导 |
| 根本政治制度 | 人民代表大会制度 |
| 首要任务 | 高质量发展 |

要求：

- 只收**反复考**的搭配，20–30 条，不超过一页。
- 同一关键词有多个答案时，写清限定语（如"总抓手（法治）"）。
- 提词器必须能脱离正文单独使用。

### 大题答题结构

不要让学生背整段，给可拼接的骨架：

```
定义/定性（1 句）
+ 背景/原因（1–2 点）
+ 内容/举措（3–4 点，分点写）
+ 意义/地位（1–2 点）
```

判卷看关键词，答案里必须出现本章的固定表述。老奶版解释"为什么这句能得分"，薄肌版给"必须出现的词"。

### 选题

- 题库有原题就优先原题，答案以题库为准。
- 按**归一化题干**去重：去掉标点、数字、选项后，相似度 ≥ 0.86 视为重复（`check_docs.py` 会抓）。
- 题库覆盖不到的章节，补 1 道 AI 题并标 `{{AI补充}}`，不要空着。
- 3 小时：每章 1–2 题；1 天：每章 3–5 题；1 周：全题库 + 错题二刷。

### 时间分配

| 时长 | 打法 |
| --- | --- |
| 3 小时 | 10 分钟提词器 → 140 分钟过章（每章 7–8 分钟）→ 30 分钟做题 |
| 1 天 | 上午过全书必背，下午做题，晚上只背提词器和易混 |
| 1 周 | 第一遍理解，第二遍背表述，第三遍刷题库，最后两天只过错题 |

### 四个坑

1. **把"根本/基本/首要/核心"混着背。** 这类词就是考点，必须成组记。
2. **只背解释，不背原话。** 大题判卷按关键词，口语化改写会丢分。
3. **编造表述。** 不确定的原话不要写，标"材料未覆盖"。
4. **每章都平均用力。** 按题库题量和重要度分配，低频章整章压缩。

## 四、医学 / 法学案例

- 医学：症状 → 首选检查 → 诊断（符合几条标准）→ 治疗（一线/禁忌）→ 鉴别。
- 法学：法律关系 → 适用法条 → 要件涵摄（逐条对）→ 结论 → 例外。
- 每道案例题按这条链写，缺一环就丢分。
- 题目答案以材料/法条为准，不凭印象补法条号。

---

## 怎么选

1. 材料里有大量公式、计算、推导 → 理科或工科。
2. 材料以条目、表述、时间线为主，题库是选择/判断 → 文科记忆。
3. 材料是病例、案情、要件 → 医学/法学案例。
4. 跨学科课程按**考试题型**选，不按院系选。

在边界卡里写明用了哪套模板，后续所有章节保持一致。
